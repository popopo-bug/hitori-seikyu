請求書作成ツール（無料・登録不要・インボイス対応）

入力するとすぐに完成イメージを確認でき、そのままA4のPDFで保存できます。発行者情報は一度入れれば次回から自動で入ります。

  • 登録・ログイン不要
  • インボイス（適格請求書）対応
  • 源泉徴収の自動計算
  • 8%・1%・10%の混在OK
  • データは端末内だけ

使い方（3ステップ）

  1. 発行者情報（あなたの情報）を入れる — 屋号・氏名・登録番号・住所・振込先。初回だけで、次回からは自動で入ります。
  2. 宛先と明細を入れる — 品目・数量・単価を入れると、税率ごとの消費税と合計が自動で計算されます。
  3. 「PDF保存・印刷」を押す — 印刷画面で「PDFに保存」を選べば完成。メールに添付して送れます。

見積書・納品書・領収書もタブで切り替えるだけ。入力した内容を引き継ぐので、見積書 → 請求書 → 領収書の作成がすぐに終わります。

インボイス（適格請求書）に必要な記載事項

登録番号のある事業者が交付する請求書（適格請求書）には、次の6つを記載する必要があります。このツールは入力状況をチェックし、足りない項目をお知らせします。

  1. 発行者の氏名または名称、登録番号（T＋13桁）
  2. 取引年月日（納品日や「2026年10月分」など）
  3. 取引内容（軽減税率の対象品目であればその旨）
  4. 税率ごとに区分して合計した対価の額と適用税率
  5. 税率ごとに区分した消費税額
  6. 書類の交付を受ける事業者の氏名または名称（宛先）

消費税額の端数処理は「1枚の請求書につき税率ごとに1回」がルールです。詳しくはインボイス対応の請求書の書き方で解説しています。

源泉徴収が必要な報酬にも対応

デザイン料・原稿料・講演料など、個人に支払う一定の報酬は、支払う側が源泉徴収します。「源泉徴収をする」をオンにすると、100万円以下は10.21%、100万円を超える部分は20.42%で自動計算し、差引のご請求額を表示します。立替金など対象外の明細は行ごとに外せます。金額だけ確認したいときは源泉徴収 計算ツールが便利です。

2027年からは消費税の「3割特例」に

インボイス登録で課税事業者になった個人事業者が使える「2割特例」は2026年分で終了し、2027年・2028年分は「3割特例」になります。納税額がどれくらい増えるかは消費税 3割特例シミュレーターで確認できます。

2027年4月からの「食料品1%」にも対応

飲食料品の消費税が2年間1%になる改正（法案成立が前提）に合わせて、明細の税率で「1%軽減」を選べます。3月分（8%）と4月分（1%）が混ざる請求書も、税率ごとに自動で区分します。食料品1%の請求書・領収書の書き方

よくある質問

本当に無料ですか？回数制限はありますか？

無料で、回数の制限もありません。請求書・見積書・納品書・領収書の作成とPDF保存はすべて無料です。サイトは広告・アフィリエイト収入で運営しています。

入力した情報はどこに保存されますか？

お使いのブラウザの中（localStorage）にだけ保存され、当サイトのサーバーへは送信されません。ブラウザのデータを消去すると消えます。共有パソコンで使ったあとは「新しく作る（入力をクリア）」を押してください。

登録番号がない（免税事業者）でも使えますか？

使えます。登録番号を空欄にすると、通常の請求書として出力されます。

PDFで保存するにはどうすればいいですか？

「PDF保存・印刷」を押し、印刷画面の送信先で「PDFに保存」を選びます。用紙はA4、「ヘッダーとフッター」はオフがおすすめです。スマホでは印刷画面の共有メニューからPDFを保存できます。ファイル名は「日付_取引先_書類名_金額」で自動的に入ります。

消費税の端数処理はどうなりますか？

インボイス制度のルールどおり、1枚の書類につき税率ごとに1回だけ端数処理します。切り捨て・四捨五入・切り上げから選べます。明細ごとに端数処理すると要件を満たさないため注意してください。

2027年4月からの食料品の消費税1%に対応していますか？

対応しています。明細の税率で「1%軽減」を選ぶと1%で消費税額を計算し、8%・10%と混ざる請求書も税率ごとに区分して表示します（法案が成立した場合の制度にもとづきます）。

請求書に印鑑は必要ですか？

法律上の義務はありません。慣習として押したい場合は、文字から作る電子印影か、印鑑を押した紙を撮影した画像を使えます（背景は自動で透明になります）。
